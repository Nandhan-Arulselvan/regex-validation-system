Strong Password
Policy Enforcer

A live demonstration of how regular expressions can express and enforce several structural rules at once—while also giving understandable requirement-by-requirement feedback.

Why enforce a password policy?

Password policies set a minimum structure that makes simple passwords less likely to be guessed. Regex is well suited to this structural check: character classes recognize types of characters, quantifiers express length, anchors check the entire value, and lookaheads require a feature without consuming it. A regex policy tests form; it does not measure uniqueness or whether a password has been leaked.

✓ Minimum length: 12 characters
✓ At least one uppercase letter
✓ At least one lowercase letter
✓ At least one number
✓ At least one special character
× Whitespace is not allowed

The password regular expression

This single pattern combines all requirements. Each positive lookahead (?=...) checks that a required character appears somewhere ahead without moving the matching position. The final character class restricts every character, and {12,} enforces minimum length.

ACTUAL JAVASCRIPT REGEXPANCHORED FULL MATCH
^ begins the full-input check. (?=.*[a-z]), (?=.*[A-Z]), (?=.*\d), and (?=.*[!@#$...]) are positive lookaheads: each must succeed for the whole regex to accept.
The .* inside a lookahead scans forward for at least one character matching the following class. Since lookaheads do not consume input, every requirement can inspect the same password.
  • [a-z] requires a lowercase English letter.
  • [A-Z] requires an uppercase English letter.
  • \d requires a digit.
  • [^\s] means any non-whitespace character.
  • {12,} means 12 or more occurrences.
  • $ ensures the complete password is checked.

Models of Computation connection
Let L_PASSWORD be the language of every string satisfying this policy. A password is accepted only when it belongs to that language. This translates the practical rule set into the computation sequence below: a regular expression specifies a regular-language-style pattern, pattern matching evaluates the input, and the system presents acceptance or rejection.
